# FitBridge｜健身房新手入门助手

FitBridge 是一个面向墨尔本中国留学生健身新手的微信小程序概念项目。它把健身房里的器械说明、双语名称、场馆位置和预设替代动作整理在一起，帮助新会员更快找到器械并理解基本使用信息。

> 本仓库包含产品分析、PRD 和可交互的前端概念 Demo。Demo 使用模拟场馆与示例内容，不连接微信、健身房系统或真实会员数据，也不提供经专业人士审核的运动指导。

## 项目概览

- **用户**：在澳大利亚健身房锻炼、对器械不熟悉的中国留学生，优先关注新手。
- **客户**：服务国际学生的墨尔本独立健身房或小型连锁；会员免费使用，健身房付费的商业模式仍待验证。
- **核心体验**：扫码/进入小程序 → 选择场馆 → 搜索或浏览器械 → 阅读中英双语说明 → 查看位置与被占用时的预设替代项。
- **证据边界**：探索性便利抽样调查中，37/45 名回答者报告首次去澳洲健身房时遇到困难。调查不能代表全部留学生，也没有证明真实使用、付费意愿或留存改善。

## 运行 Demo

直接打开 `demo/index.html` 即可，无需安装依赖或启动服务。建议用手机尺寸浏览器查看。

已实现：演示场馆切换、器械搜索、分类筛选、器械详情抽屉、使用步骤、预设替代动作、收藏切换和底部导航状态。场馆切换不代表真实场馆内容同步，页面内容均为演示数据。

## 产品判断

### 已有信号

- 调查中 37/45（82%）表示首次到澳大利亚健身房时遇到过困难。
- 47 名回答者中，29 人选择了“小红书/YouTube”这个合并选项来解决问题；这个选项不能拆分成两个渠道的数据。
- 功能偏好题（n=47）中，中文说明配英文器械名称获 47 次选择、器械被占用时的替代项获 38 次、器械位置获 34 次。

### 仍待验证

- 新手会否在真实健身房里找到并重复使用 FitBridge。
- 具备采购权的健身房决策者是否愿意付费，及其接受的定价方式。
- 每个场馆的数据采集、内容复核与更新成本是否可持续。
- 预设替代内容是否安全、准确；正式上线前需要合格健身专业人士审核。

## 技术实现

当前 Demo 是原生 HTML、CSS 和 JavaScript 的可点击原型，方便快速讨论信息架构和关键路径。后续若进入微信小程序实现，可将页面迁移为原生小程序或跨端框架，并接入经授权的场馆器械数据、内容管理和基础事件分析。
